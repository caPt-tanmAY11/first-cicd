# First CI/CD

An Express.js REST API deployed to AWS EC2 using Docker,
GitHub Actions, GitHub Container Registry (GHCR), and AWS Systems Manager.

## Features

- Health-check endpoint
- Task CRUD APIs
- Input validation and error handling
- Automated API tests using Node.js Test Runner and Supertest
- Dockerized application
- Automated CI/CD deployment

## Run locally

```bash
npm ci
npm start
